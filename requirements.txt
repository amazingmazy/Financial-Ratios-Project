# A note on the wrds floor, because it is load-bearing
# ---------------------------------------------------------------------------
# `wrds>=3.5` is not cosmetic. Asking for a bare `wrds` lets a resolver satisfy
# a newer pandas by reaching back to wrds 3.1.6 (2023), which passes a raw
# DBAPI2 connection to pandas.read_sql_query. pandas 3 dropped support for
# that, so every raw_sql call fails with
#
#     'Connection' object has no attribute 'cursor'
#
# and the whole data pipeline dies at the first query. wrds 3.5 uses a
# SQLAlchemy 2.x engine instead and constrains pandas to >=2.2,<2.3 itself, so
# declaring the floor here is what keeps the pair consistent. Do not "fix" a
# pandas complaint by loosening this line.
